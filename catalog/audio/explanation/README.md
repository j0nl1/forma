# audio-explanation

A guided explanation with examples and a coherent teaching arc.

The manifest describes the entry, editable parameters, requirements and source dependencies. Use `forma catalog show audio-explanation` to inspect this resource and `forma catalog add audio-explanation /absolute/project` to copy it with its manifest and dependencies.

`template.json` is an authoring blueprint. Fill the sources and script using the canonical guide, then produce and validate the episode and clip manifests. It is not a ready-to-render episode. Language, duration, engine and voices remain explicit user choices.
