# audio-summary

A concise overview preserving the source claims and qualifications.

The manifest describes the entry, editable parameters, requirements and source dependencies. Use `forma catalog show audio-summary` to inspect this resource and `forma catalog add audio-summary /absolute/project` to copy it with its manifest and dependencies.

`template.json` is an authoring blueprint. Fill the sources and script using the canonical guide, then produce and validate the episode and clip manifests. It is not a ready-to-render episode. Language, duration, engine and voices remain explicit user choices.
