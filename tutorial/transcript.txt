Skill
Studio Design is a skill: instructions, recipes, editable starters, and local helpers. Invoke it inside Codex. The website showcases working examples; it is not the skill’s product interface.

Install
Let your agent handle setup. Copy the installation prompt from the README. Your agent reviews the repository, chooses a skills folder for your harness, checks the dry run, and prepares local tools. Reload if needed, then activate Studio Design.

Brief
Give the audience, primary task, reference, and output. For example: a reading-room prototype, calm and dense directions, the Harbor style, and editable HTML. Codex reads project instructions and the relevant recipes.

Modes
Thirteen core modes cover interfaces, mobile, wireframes, documents, resumes, fliers, HTML presentations, animation, three D objects, research, email, diagrams, and color and type systems. Read only the recipes you need.

Prototype
Here, choose two interests to enter the reading room. Save an article, check validation, and confirm the result. Test recovery and keyboard behavior. This real prototype uses local sample data, with no service connection.

Canvas
A canvas compares working artboards. Inspect hierarchy and density, focus an option, and try Save. Connected local previews save supported edits to selected files; public demos keep edits in the browser.

Motion
Composition Stage keeps a persistent tree. Shots, animations, and captions follow authored time and named cues. Stretch a section or change speed without cutting its choreography. This tutorial uses that same engine.

Verify
Serve over loopback. Exercise the flow, inspect screenshots, and check the console. Export HTML, PNG, PDF, PowerPoint, or MP4 with local helpers. Keep the source folder: the HTML and code remain editable after export.

Handoff
PowerPoint supports editable slides with native builds and local media. Complex CSS can need image layers. Check fonts, animation, and media playback in the receiving application. External generation and transfers need configured providers or authorized connectors. Give a concrete brief, verify the result, and keep the editable artifact.
