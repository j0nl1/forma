# Importing design context

## Local Figma files

`scripts/forma.mjs figma outline <file.fig>` inventories pages, frames, and components offline. `mount <file.fig> <destination>` saves a navigable JSON tree and assets. `render <file.fig> <destination.html> --node <id-or-exact-name>` materializes a selected node as HTML. `materialize <file.fig> <destination> --node <id-or-exact-name>` writes selected HTML plus tokens. `design-system <file.fig> <destination>` creates a native system with extracted colors, editable React components and HTML examples, ready for the design-system compiler.

The independent decoder supports raw `fig-kiwi` and ZIP `canvas.fig`, deflate and Zstandard. It reconstructs parent-child order and preserves raw node properties and blob data in the mount. The renderer supports saved geometry, ordered solid/gradient/image fills, real text, vector path blobs, transforms, and common layout properties. Unsupported effects, mask compositing, constraints, and unavailable instance dependencies are recorded as warnings, so do not claim pixel-perfect conversion. Compare with supplied Figma exports when fidelity matters. Keep original files unchanged.

Visible drop/inner shadow stacks now render with their offsets, color alpha, radius and box spread. Text and solid vectors use their painted alpha shape; vector corners remain transparent instead of becoming a filled rectangle. SVG inner filters are embedded with the HTML and work in compiled review shadow roots. Normal layer/foreground blur and backdrop blur retain their ordered filter chains. Hidden effects do not render or produce unsupported-effect warnings. The effect fields follow the documented runtime contract and [Figma's documented effect inputs](https://developers.figma.com/docs/plugins/api/Effect/); that does not establish exact rendering equivalence across all Figma exports.

Run `materialize` or `render`, inspect returned warnings, then serve the selected HTML. Geometry retains its source dimensions while the preview can fit it to the screen; pixel checks must account for that presentation scale. Normal shadow/blur output remains usable after deleting the original `.fig`. The exported HTML contains its filter definitions; PNG export captures the painted result. Tests cover raw/ZIP imports, a separately authored box-shadow rendition, actual text/vector inner pixels, blurred foreground/background pixels, source deletion and compiled reviews.

Non-normal effect blend modes, bound variables, progressive blur, noise/glass/texture/shader effects, spread on text/vector silhouettes and explicit shadow-behind-translucent-geometry behavior still need visual review. These are pending behaviors, not silently discarded acceptance requirements. Alpha/luminance mask compositing, complex vector paints/compositing, unavailable external instances, constraints, variable modes, advanced text layout and broader Figma comparisons also remain incomplete. Generated geometry is not yet the full component/variant authoring model.

Visible paint layers now render in source order, with the last layer on top, retaining color alpha and paint opacity. Linear gradients use their transformed start/end coordinates; radial and angular gradients retain their center, size and direction. A missing transform uses the documented default geometry, while malformed/singular transforms produce an explicit advisory and default rendering. Diamond gradients retain the source materializer's radial approximation with a warning. Rotated/skewed radial ellipses also need visual review. Hidden paints neither render nor enter the extracted color inventory; gradient stop colors now enter that inventory with their paint alpha.

Image fills embed their assets in a separate SVG background layer so opacity affects only that image and does not cover children or inset shadows. FILL uses centered cover; FIT uses centered contain and retains underlying layers in the letterbox area. TILE repeats at the saved original dimensions multiplied by the saved scale, using intrinsic PNG/GIF/JPEG/WebP dimensions when the hints are absent. CROP/STRETCH use the inverse normalized paint transform. Missing or invalid crop transforms retain cover fallback with a warning. Paint blend modes use native CSS composition; unknown modes remain normal fallback advisories. Image filters and separate rotation fields remain pending and explicitly warned.

Solid and linear vector layers paint the actual paths in order, with embedded SVG gradient definitions and transparent corners. Other vector paint types remain explicit unsupported warnings. Text keeps its literal glyphs and typography while gradient/image layers clip to the glyphs. Tests compare independently authored solid-stack, gradient, blend and text regions byte for byte, sample actual image fitting/tiling/crop/stretch/alpha pixels, and verify intrinsic PNG/JPEG/WebP tile sizes. Materialized, portable HTML/PNG and compiled system reviews retain their paints after deleting the original Figma file. These checks verify the stated contracts rather than full Figma fidelity.

Box strokes now preserve the inspected materializer's last visible solid color, opacity, INSIDE/CENTER/OUTSIDE placement, rounded corners and independent top/right/bottom/left widths. Border shadows share one ordered stack with drop/inner effects, so adding a stroke does not replace an effect. Uniform strokes keep the saved box dimensions and absolute child positions. Independent CSS borders retain their measured side widths and source spacing behavior; possible child offsets and unresolved uniform `bordersTakeSpace` layouts remain explicit advisories.

Vector fill and stroke command blobs render independently. Saved stroke geometry represents filled outlines rather than a path to be stroked a second time. ODD/EVENODD paths retain holes; line/cubic/quadratic/close commands retain their finite coordinates. Contained masks keep the saved stroke inside or outside the fill for the corresponding alignment, while CENTER preserves the full outline. Stroke-only nodes and zero-height lines remain visible, including their alpha shadows and saved overflow. Solid/linear stroke paints retain their alpha and separate gradient definitions. Overlapping geometry follows the inspected per-path paint order; changing that order would change translucent colors. Visible stroke colors and gradient stops now enter the extracted inventory. Missing/malformed geometry and non-finite coordinates produce warnings without changing the input file.

Tests compare raw/ZIP border, shadow, dash-alignment, independent-side/child, vector-mask, curve, overlapping-alpha and independent fill/stroke-gradient regions with separately authored CSS/SVG bytes. Decoded pixels also verify zero-height line shadows and transparent contour holes. Materialized HTML, copied review shadow roots and real portable HTML/PNG retain their strokes after source deletion. These checks cover the stated contracts. Boxes still use the CSS dashed approximation rather than exact authored dash lengths and the last visible solid rather than a full stroke paint stack; both limitations are warned. Gradient/image box strokes, complex stroke layouts, unavailable text glyph outlines, vector-network-only geometry and broader Figma comparisons remain required work. Stroke alignment masks are separate from masks between sibling layers.

Sibling masks now clip following siblings until the next mask, including a hidden mask boundary. Saved vectors and glyphs retain winding holes and positioned outlines; rounded boxes, ellipses and composite child contours retain their full affine transforms. Container child geometry takes precedence over a bounding-box fallback. Missing usable contours produce an explicit unmasked fallback warning. Raw/ZIP contours match independently authored SVG regions, and compiled review/portable HTML/PNG retain the masks after source deletion. ALPHA/LUMINANCE modes currently warn and use a contour fallback; their full paint compositing and vector-network-only contours remain required work.

Text now retains font weight/style metadata, spacing and line-height units, decoration/case, OpenType/variation settings and literal character style runs. Literal ordered/unordered line prefixes retain indentation and numbering resets; UTF-16 character-style offsets account for newline characters, and sparse style IDs use the base style. SUPS retains the inspected superscript font-size/vertical-align fallback. Saved glyph blobs render positioned, scaled and rotated contours with winding holes, node-coordinate solid/linear/image fills and inside/center/outside strokes. Image FIT/TILE/CROP and alpha remain embedded; default empty fills and missing-image fallbacks follow the documented runtime contract. Glyph background blur clips through the contours instead of affecting their entire box. Accessible literal characters remain in the output. Raw/ZIP typography and stroke silhouettes match independently authored CSS/SVG; actual pixels verify gradients, rotated contours, alpha shadows, images and backdrop holes. Reviews and portable HTML/PNG retain them after source deletion. Missing/invalid outlines use a warned literal fallback. Font asset resolution and paragraph/truncation layout remain required work. Literal lists follow the inspected prefix-based rendering; saved-glyph decoration and per-glyph style paints remain documented source limitations.

Generate editable React modules for every component set or standalone symbol:

```bash
node <skill>/scripts/forma.mjs figma components source.fig output-folder
node <skill>/scripts/forma.mjs figma components source.fig selected-folder --node "1:42"
```

Each module has a sibling `.d.ts`; `components.json` records defaults, source node IDs and every emitted variant's props. Exact names, generated names and variant child IDs also select a component; ambiguous names require a node ID. Names are bounded safe identifiers, reserve generator imports and deduplicate case-insensitively for portable filenames; variant children belong to their set instead of becoming duplicate exports. Variant value orders, size aliases, boolean axes and inherited property IDs determine the public props. Unknown combinations use the default body; collisions warn and retain the first reachable variant.

The generated JSX contains ordinary editable elements rather than opaque HTML injection. Declared text and visibility bindings update their corresponding nodes; instance-swap bindings accept React content. Root `className` and `style` remain overridable. Per-instance SVG identifiers prevent repeated components from sharing mask/filter definitions. `design-system` now includes these modules and their contracts alongside its visual examples, so the existing check/compile/preview workflow provides real component samples. Tests compare live raw/ZIP variant pixels against independently authored CSS/SVG and verify copied reviews and portable React HTML/PNG after deleting the input and system sources.

Local instances without cached children now expand their masters for raw rendering, retaining ordered nested overrides, property assignments, swaps and independent SVG definitions. Raw instances with saved children keep those children. Generated React uses local component calls and automatically emits their dependency closure; declared direct overrides become props and complex nested overrides become editable baked elements with advisories. Unavailable external masters remain sized placeholders or supplied React slots. Recursive dependencies use bounded baked resolution. Fixed-size non-stack instances retain independent horizontal/vertical scaling.

Generated horizontal/vertical auto layout uses flex direction, grow/stretch, inferred or declared hug sizing, wrap, padding/gaps, alignment and min/max sizes. Absolute or rotated children retain saved placement. Ordinary generated text uses literal fonts/runs so hug sizing can measure content; recognized icon fonts now emit saved outlines in a real SVG flow box. Each icon retains width/height/viewBox, source-rounded positions/rotation and currentColor; the first visible solid fill sets its own color, while root styles remain overridable. Declared text bindings stay literal and missing outlines use an explicit fallback. Closed vector-network regions supply component paths only when both saved fill and stroke geometry are absent; raw rendering and mask contours do not use this fallback.

GRID now uses source-ordered fixed/auto/fraction/minmax tracks, row/column gaps, padding and child anchors/spans/alignment/stretch. Absolute children keep saved placement; GRID parents and ordinary children keep saved dimensions unless explicit stretch applies. GRID child transforms remain unchanged. Calls in horizontal/vertical stacks explicitly override master dimensions with auto for grow/stretch. GRID calls retain the inspected asymmetry: vertical stretch sets height to auto, while horizontal stretch leaves width unspecified and can retain the master width.

Eligible unbound content now exposes up to four numbered text props and four numbered icon slots. Planning follows per-variant depth-first order and recognizes overrideKey aliases. It excludes blank, icon-font, mixed-style, already-bound, hidden/unreachable and internal data; instances/vectors do not expose descendant text. A declared text1–text4 key disables both synthesis families, while icon1–icon4 keys disable only icon synthesis. Lists retain their literal runs rather than becoming a synthetic text binding. Actual emitted slots appear in the declarations; text fallbacks remain per-variant. Direct single-path text and component-swap overrides target these props, with local dependencies and source scale/resize rules. Complex overrides keep bounded baked bodies.

The importer supports these tested instance/layout/network/GRID/synthesis/icon contracts. Token/typography-variable wiring, font assets, broader source metadata workflows and additional generator coverage remain required work. ALPHA/LUMINANCE mask paint compositing and per-glyph paint/decoration resolution are approximate. Contour fallback and node-wide glyph paints are reported through advisories.

For live Figma access or a faithful screenshot, use the installed Figma connector if available and authorized; follow its skill requirements. Do not silently require an account for offline inventory.

## GitHub and codebases

Read repository metadata, license, and selected files with `gh api` or ordinary read-only HTTP. Pin the commit and keep a source snapshot outside the project. Do not execute install hooks, examples, or upstream scripts merely to obtain context. Extract typography, tokens, component contracts, states, and assets from source, then write a native system or prototype.

## Existing HTML/CSS

Inspect source and local dependency paths before rendering. Preserve useful tokens, layout, content, and interactions. Imported JavaScript is active code; inventory can be done without executing it. Copy permitted assets into the deliverable and retain attribution. For a faithful recreation, compare screenshots after rebuilding.

`.napkin` or other sketch files should use supplied thumbnails when available. Raw sketch JSON is supporting data, not a ready-made screen.
