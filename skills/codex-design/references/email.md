# HTML email

Start from `email.html`. Use a table-based structure, inline critical CSS, system fonts, explicit image sizes, descriptive alt text, and a readable plain-text equivalent when requested. Target width is typically 600px with a fluid outer wrapper.

Avoid JavaScript, custom elements, flex/grid dependencies, external CSS, embedded forms, and autoplay media. Use links for calls to action. Some clients suppress images; the message and action must remain understandable. Keep text as text.

A browser screenshot checks layout only. Do not claim Outlook, Gmail, or mobile email-client compatibility without testing there. Use the user's actual unsubscribe and legal copy when needed, and do not fabricate delivery credentials or send the email unless explicitly authorized.
